# 审计报告 (Audit)

> **定位**：保存人工主导、可复核的代码质量审计报告与只读模板。
>
> **边界**：本目录是审计档案，不是机器报告目录，也不是问题跟踪系统；当前问题状态只以各报告第 8 章为准。

---

## 1. 用途

本目录存放：

- 只读审计模板：`AUDIT-000-audit-template.md`；
- 按模板生成的正式审计/复审报告：`AUDIT-XXX-code-quality-audit-<日期>.md`；
- 报告内的证据、问题总表、路线图与复审记录。

不存放：

- 门禁、契约、覆盖率等机器报告（在 [`../reports/`](../reports/README.md)）；
- 临时探针、解包目录、逐文件迁移台账；
- 未经验证的个人笔记或未确认的缺陷猜测。

---

## 2. 命名与编号

| 项目 | 规则 |
|:---|:---|
| 模板 | `AUDIT-000-audit-template.md`，只读，不填写具体结论 |
| 正式报告 | `AUDIT-XXX-code-quality-audit-YYYY-MM-DD.md` |
| 编号 | 三位数字，从 `001` 起，按实际报告递增，不复用、不回退 |
| 问题身份 | `AUDIT-XXX:<PREFIX>-NNN`；跨报告必须带命名空间 |
| 证据身份 | `EVID-NNN`，仅在当前报告内稳定，不参与问题编号 |

`AUDIT-000` 是模板保留编号，不代表一次实际审计。

---

## 3. 档案规则

1. **报告第 8 章是唯一状态源**：首页看板、结论与修复路线图必须与第 8 章一致。
2. **历史报告只追加、不改写**：原始发现证据、基线、旧结论与风险接受记录保留；复审在接续报告或当前报告第 7 章追加。
3. **已关闭必须有直接证据**：原始证据保留，并补充覆盖原触发条件的验证/复审引用，或消除该路径的静态证明；默认测试绿灯、只改注释或一次不崩溃不能关闭消费者缺陷。
4. **已暂缓 / 已缓解必须可追踪**：写明风险接受原因、重开条件与复审时间。
5. **只读审计**：审计过程不修改 `source/`、ADR、既有文档或历史报告；修复另开迭代。
6. **隔离验证**：运行门禁或运行时夹具前确认不会覆盖真实 `user://` 存档、设置与日志；无法安全隔离的项目标记受限。
7. **公共仓库边界**：`source/Art/`、`Music/`、`Font/`、`Spritesheet/` 可能缺失，缺失资源提示不自动构成缺陷；完整审计以本地合法素材工作区为准。
8. **机器报告不入库**：`docs/reports/` 由脚本生成，不提交历史报告；审计报告只引用必要结论与证据。
