## 2. 项目画像

### 2.1 项目类型与核心能力

- 项目类型：**Godot 4 横版动作 RPG**，由 Flash 历史底座正位提纯并迁移；单一活跃工程位于 `source/`。
- 核心能力：
  1. 多角色横版移动、普攻、技能、无双、法宝与剑阵；
  2. 关卡阶段刷怪、Boss、掉落、通关进度与自动战斗；
  3. 本地双人（1P/2P 独立档案、共享部分进度）；
  4. 装备、锻造、背包、商店、任务、宠物、坐骑、丹药、万灵图录等成长系统；
  5. 加密存档、后台保存、`.bak` 恢复与云存档导入/导出；
  6. 构建期 SpriteFrames/AtlasMetadata、Spine 骨骼特效与运行时缓存/预热。

### 2.2 技术栈与运行环境

| 类别 | 当前值 |
| --- | --- |
| 引擎 | Godot **4.7.2** |
| 语言 | GDScript 2.0，优先静态类型 |
| 渲染 | 默认 `mobile`；Web 使用 `forward_plus` |
| 主场景 | `res://Scene/other_scene/load_scene.tscn` |
| 工程配置 | `source/project.godot`：Autoload、输入动作、具名 2D 物理层、显示与渲染（数量以审计时实际配置为准） |
| UI/场景 | `.tscn` 场景树；`Global.add_*` 工厂与弹窗层 |
| 数据 | `PlayerData` 巨型字典 + `DataKeys`；新增结构化数据优先 Resource/Manifest |
| 持久化 | `MemoryClass` 加密 JSON、`.tmp`/`.bak` 原子写、后台线程、`user://.save_key` |
| 资源 | SpriteFrames、AtlasMetadata、Spine、构建期转换器、运行期缓存/预热/对象池 |
| 验证 | Python 门禁/回归脚本 + Godot headless；无独立单元测试框架 |
| 平台边界 | Spine 运行库当前仅 Windows x86_64 入库；Steam Deck 全屏与 Android 实机未完整验证 |
