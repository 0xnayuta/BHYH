## 1. 当前迭代：6.9 补丁回植（实施中：6.9-1 至 6.9-5 已完成）

6.9 目标二进制的只读预检、PCK 目录校验与脚本反编译已完成。6.9 是**补丁型更新**：公告范围包含 12 项双人、自动战斗、任务与掉落修复；变更清单为 20 个生产脚本、2 个生产场景，无新增生产资源；新增的 6 个 PCK 条目均为测试探针，不进入生产工程。

当前内容版本仍为 **6.8**；6.9-1 至 6.9-5 已完成，6.9-6 场景/资产/全量验收待开始。实施顺序、文件映射、风险与定向验收矩阵见 [`current-iteration.md`](current-iteration.md)。

1. 固定 6.8/6.9 参考脚本、场景与 manifest，建立临时逐文件台账；
2. 按基础数据/任务、掉落装备、双人共享、自动战斗/UI、场景收口分批做三方语义合并；
3. 仅合入生产文件；不复制上游 `Test/`、`.remap`、`uid_cache.bin` 或旧导入缓存；
4. 通过静态门禁、引擎健康检查、关卡回归、双人探针与定向场景验收；
5. 验收完成后更新 [`../reference/status.md`](../reference/status.md) 的版本、规模与基线。

通用方法与红线见 [`../guides/migration_playbook.md`](../guides/migration_playbook.md)。

## 2. Godot 设计规范落地

当前工程仍包含 Flash 正位重构遗留结构。后续新代码与主动重构按 [`../standards/godot_design_standard.md`](../standards/godot_design_standard.md) 执行：

- 场景单一职责、自包含、依赖注入；
- 新代码禁止深层 `get_node()` 与绝对路径；
- 新结构化数据使用 `Resource` / `.tres`；
- 新增 Autoload 必须评审；
- 输入动作与物理层使用具名配置；
- 遗留结构不阻塞功能，但不得继续扩张。

## 3. 技术债治理

按独立项目推进，不混入普通功能提交：

| 项目 | 目标 |
|:---|:---|
| `global.gd` 与字典数据 | 逐步拆分为 Resource、服务节点或强类型数据入口 |
| 13 个 Autoload | 降低耦合，新增 Autoload 需评审 |
| 类型分层目录 | 新功能按功能子目录聚合，不做无计划全量迁移 |
| `_bundled` 场景 | 按专项转换为原生文本场景，完成 UID 与导入缓存重建 |
| 深层节点路径 | 新代码使用依赖注入与 `%UniqueName`，重构时同步清理 |

---

## 4. 质量与工具链

- 保持 `check_all.py` 七维门禁与 0 ERROR / 0 WARNING；
- 报告由脚本按需生成，不提交历史报告；
- 保持门禁命令、报告路径和文档索引同步；
- 新增脚本只进入 `scripts/`，版本专用迁移工具不进入日常工具链；
- 公共仓库继续排除第三方素材；完整工作区验收以本地合法素材为准。

## 5. 验收基线

每个阶段结束时更新 [`../reference/status.md`](../reference/status.md)：

- 当前内容版本；
- 工程规模；
- 静态门禁、引擎健康检查、关卡回归与 Atlas 校验结果；
- 已知边界与未完成技术债；
