# 路线图 (Roadmap)

本目录保存长期阶段顺序、当前候选与恢复入口。

## 1. 当前文档

| 文档 | 内容 |
|:---|:---|
| [`roadmap.md`](roadmap.md) | 项目状态、长期阶段顺序与近期重点的唯一来源 |
| [`current-iteration.md`](current-iteration.md) | 当前候选；无活跃候选时明确写“无” |
| [`../archive/README.md`](../archive/README.md) | 已完成阶段的实施记录与长期参考 |

## 2. 边界

- 本目录只写阶段目标、依赖、边界与验收要求，不记录逐文件实施台账。
- 已完成阶段移入 `archive/`，不在此复制批次耗时、截图或历史计数。
- 当前候选的选择条件与恢复入口见 `current-iteration.md`。
- 阶段归档流程见 [`../archive/README.md`](../archive/README.md)。
