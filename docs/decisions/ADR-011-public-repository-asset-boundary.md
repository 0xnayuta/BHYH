# ADR-011：公开仓库排除第三方素材，代码采用 MIT

- **状态**：Accepted
- **记录日期**：2026-10-25
- **影响范围**：许可证、仓库边界、发布、可复现性

## 背景

工程的 `Art/`、`Music/`、`Font/`、`Spritesheet/` 包含第三方游戏素材，不能随代码公开分发。仓库需要作为代码、场景与工具链快照公开，同时避免暗示对素材的再分发授权。

## 决策

1. `.gitignore` 排除 `source/Art/`、`source/Music/`、`source/Font/`、`source/Spritesheet/` 及其导入产物；
2. 禁止使用 `git add -f` 绕过忽略规则；
3. 自有代码采用 MIT；
4. 第三方组件与运行时分别在 `THIRD_PARTY_NOTICES.md`、`LICENSE` 与组件许可证中声明；
5. 公开 clone 不保证可直接运行，缺少素材导致的资源缺失属于预期；
6. 完整验收在本地合法授权的完整素材工作区执行；
7. 新增公开素材或改变 `.gitignore` 边界必须经过评审并更新许可证说明。

## 后果

- 公开仓库法律风险可控；
- 外部贡献者无法直接复现完整运行画面，需要自备合法素材；
- 发布包与公开仓库的内容边界必须分别检查；
- 素材相关的测试、截图与报告不能作为公开仓库的必需产物。

## 备选方案

| 方案 | 未采用原因 |
|:---|:---|
| 将素材一并公开 | 无再分发授权，法律风险高 |
| 使用 Git LFS 存放大文件 | 只解决体积，不解决授权问题 |
| 不公开任何代码 | 与项目开源目标冲突 |
