## 2. 关键实现

- 相机：`DESIGN_ZOOM = 1.2`，并按窗口高度计算纵向偏移，保留 Phase 12-1 的原屏幕下边缘，避免扩大视野后露出关卡下方清屏色；相机抖动在基础偏移上叠加。
- HUD 安全边距：
  - HP/MP：P1 左上角 `(0, 0)`；P2 右上角 `(0, 0)`，保持水平镜像；
  - 按钮组：底部居中、底边距 4；
  - 无双/技能栏：单机 X=0；双人 P1 左侧/底部贴边、P2 镜像右侧/底部贴边；
  - FPS/显存：右上角，右边距 24；双人模式顶部偏移 164 避让 P2 等级。
- 图标语义：宠物 `500`、设置 `486`、技能 `465`、法宝 `472`、背包 `479`。
- 2P 角色本体：`base_hero.change_body/change_eq` 改用当前 hero 所属存档的 `Myself` 选择角色贴图，避免 2P 唐僧使用 1P 悟空的 `role_1` 身体/装备资源。
- 无双圆盘：移除 `grey` 节点的 180° 旋转 + Y 轴翻转，修复“无双”水平镜像。
- 双人技能栏：P2 使用负 X 缩放形成 1P 的镜像形态；`grey` 使用 `flip_h`、按键标签反向子缩放，保持文字正常可读。
- 最终按钮栏：单/双人统一为底部居中 5 按钮（54×54、间距 5、底边距 4），移除菜单按钮及 `set_list` 收展脚本。
- 最终双人技能栏：基尺寸 364×134，统一 0.85 缩放（实际 309.4×113.9）；P1 左/底 0，P2 镜像右/底 0。
- P2 技能键位标签：使用小键盘 `3/4/5/6/8`，镜像后视觉顺序为 `8/6/5/4/3`，与各技能槽一一对应。
- 无双圆盘：P1/单人 `grey.position.x=85`，P2 镜像 `x=82`，补偿翻转贴图的非对称内容中心；Y 均为 86。
- 最终性能 HUD：双人 FPS/显存顶部偏移 164，避开 P2 等级显示。
- 法宝按钮：`backpack.gd` 延迟解析当前关卡并增加有效父节点回退，修复未装备法宝时 `instance_scene got null or invalid parent`。
- 性能 HUD：FPS/显存从左上角迁移到右上角，双人模式避让 P2 状态栏。
- 双人模式：P2 技能栏使用负缩放镜像并保持文字正常；按钮组底部居中 5 列。
- 超宽屏：`BackGround/End` 增加 1440px 的 `motion_mirroring`，消除 21:9 下右侧默认清屏色。

## 5. 已知边界

1. **Steam Deck 全屏与 Android 实机**：本轮环境无对应硬件；1280×800 窗口模式已验证，全屏/移动端仅做静态与代码路径检查。
2. **21:9 静态背景**：使用 1440px `motion_mirroring` 覆盖，默认清屏色已消除；由于是重复静态背景，部分关卡可能在镜像接缝处出现轻微重复/接缝，需要后续美术资源层面优化。
3. **全关卡视觉抽检**：全量 133 关完成功能回归；21:9 视觉抽检覆盖 `level_1`、`level_10`、`level_22`、`level_59`，未对全部 133 关逐帧截图。
4. 单人与双人的暂停、自动战斗入口、返回菜单沿用既有逻辑；双人面板/暂停路径由 `LocalCoopPanelProbe` 覆盖，未新增交互层代码。
