## 2. 边界

- 规范约束见 [`../standards/`](../standards/README.md)；
- 当前状态与验收基线见 [`../reference/status.md`](../reference/status.md)；
- 构建、开发、发布、排障指南可在本目录继续增加，并同步更新本页与 [`../README.md`](../README.md)。

指南中的命令应以仓库当前路径为准；本地二进制、解密沙盒和绝对路径不写入文档。
