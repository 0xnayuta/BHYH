# 运行时调用面与所有权边界（当前）

> **状态**：Phase 15 已完成并归档；本页保留当前场景流、加载、缓存/租约、清理与退出边界。完整调查与批次记录见 [`../archive/iteration_15_runtime_lifecycle_matrix.md`](../archive/iteration_15_runtime_lifecycle_matrix.md)。

## 1. 场景流

- `Global.change_scene` 是业务唯一正式入口；业务代码不得直接调用 `change_scene_to_file/packed`。
- 加载页在 `_ready` 固定目标与请求代次，后续不读取可变全局目标；空目标、非场景、缺失目标由正式入口拒绝。
- 加载失败、实例化失败、加入后失效或取消：保留加载页并显示失败，不提交未完成目标。
- 切换中再次切换：新请求获胜；旧请求的结果不得写缓存或替换当前场景。

## 2. 缓存与租约

| 资源 | 所有者 | 生命周期 |
|:---|:---|:---|
| 资源/怪物场景/纹理/音频缓存 | `Global` / `ResourceRuntime` | 按作用域清理；不跨档案保留不可变战斗缓存 |
| 关卡资源租约 | `Global` / `ResourceRuntime` | 每次场景切换重建；只释放本租约拥有的路径 |
| 预载单槽 | `Global` | 目标/代次绑定；失败、换目标或显式清理 |
| 战斗池 | `Global` | 关卡切换保留；档案结束/应用退出清理 |
| 临时 UI | `UiRuntime` | 关闭回调 + 登记实例清理；永久小 UI 跳过 |

加载页只使用窄接口 `is_resource_cached`、`get_cached_packed_scene`、`handoff_loaded_resource`，不直接读写私有缓存。

## 3. 清理与退出

- 场景切换清理旧场景、加载页临时状态和旧代次异步请求。
- 档案结束：结束 session、停止 BGM、清理角色/战斗/UI 缓存、池和预载槽；具体事件以代码为准。
- 应用退出：`Global._exit_tree` 统一收尾；后台保存线程由 `MemoryClass` 独立 flush。
- 异步预热/纹理请求写回前检查运行时代次；过期结果丢弃，不得写活动 SceneTree。
- 节点释放后不得继续轮询；加载页/HTTPRequest 在退出时取消并检查 `is_inside_tree`。

## 4. 失败语义

| 场景 | 当前语义 |
|:---|:---|
| 无目标/无效目标 | 入口返回失败并警告；不进入加载页 |
| 加载失败/取消/超时 | 保留加载页状态；不切换 current_scene |
| 旧请求迟到 | 代次不匹配时丢弃 |
| 资源缺失 | 明确失败；不回退到源目录扫描或私有缓存 |
| 退出时有未决保存 | 先 flush；后台过期结果不写回 |
| 池/临时 UI 残留 | 清理入口负责；消费者不得复用未重置节点 |

具体调用面、旧计数和逐批验证见归档；新增场景入口、缓存或池路径必须同步守卫与验收。
