# 运行时场景、资源与退出边界

> **职责**：回答场景请求如何获得、交接、失效和退出；完整场景拓扑与资源服务结构见 [`architecture.md`](architecture.md) §3.2、§6.5，档案会话与保存见 [`archive_session_matrix.md`](archive_session_matrix.md)。

## 场景请求

- `Global.change_scene()` 是业务正式切场景入口。目标须为存在的 `.tscn` / `.scn`；默认情况下进入 `res://Scene/level/` 还须有活动档案会话。同步拒绝时返回 `false`，不推进请求代次、不清理现有运行态。
- 接受请求后，`SceneFlow` 推进场景与运行时代次，清理已登记临时 UI 和 UI 缓存、释放旧关卡租约，再为目标建立新租约。匹配的预载关卡（玲珑塔例外）可直接快速切换；其余目标进入加载页。
- `true` 只表示引擎接受了本次切换调用，不代表异步加载、实例化或最终场景交接成功。
- 加载页 `_ready` 固定目标路径与请求代次。后续轮询、资源交接和切换提交必须仍属于该请求；加载页通过公开缓存查询/读取/交接入口与 `Global` 通信，不写私有缓存。

## 资源与 UI 生命周期

- `ResourceRuntime` 持有资源缓存、单槽场景预载和当前关卡租约；租约只释放明确登记的路径，不把目标场景、永久小 UI 或未登记资源当成本租约所有物。不得按路径前缀扩大释放范围。
- 预载单槽与目标路径绑定；消费、失败、换目标或显式清理时清空。缺失/失败路径不构成可交接资源。
- 异步加载、预热写回前检查运行时代次。`ResourceLoader` 的后台请求不能由场景切换取消；旧请求停止轮询和提交，迟到资源被丢弃。
- 场景请求先清理已登记临时 UI，再按场景/档案作用域释放 UI 缓存。登记的关闭回调先执行；永久小 UI 不按普通临时实例释放。面板自己的关闭保存语义见 [`ui_panel_contract_matrix.md`](ui_panel_contract_matrix.md)。
- 战斗对象池跨关卡保留，档案结束和 `Global` 退出时统一清理；应用退出时 `Global` 使运行时代次失效并清理缓存、池、音频与 UI 状态。待写档案由 `MemoryClass` 独立 flush，见 [`archive_session_matrix.md`](archive_session_matrix.md)。

## 失败与退出语义

| 情形 | 当前边界 |
|:---|:---|
| 空、缺失或非场景目标；默认要求会话但会话无效 | 切换入口同步拒绝；不开始新加载。 |
| 加载、实例化或加入场景树失败 | 加载页显示失败并保留；不把未完成目标作为成功场景提交。 |
| 新场景加入后、交接完成前失效 | 清理本次新实例并保留加载页（或当前加载页已退出时置空）；不恢复旧的可玩关卡。 |
| 目标代次过期 | 旧页不写缓存、不提交场景；已加入树的旧结果释放。 |
| 加载超时 | 只将加载页置为失败并清空本页待处理队列；不代表底层线程请求已取消。 |
| 加载页退出 | 停止轮询/交接并清本页队列；资源线程请求仍由引擎完成后丢弃。 |
| 缓存资源缺失 | 公开读取返回空/失败；不在运行时扫描源目录或猜测替代路径。 |

历史实施细节见 [`../archive/iteration_15_runtime_lifecycle_matrix.md`](../archive/iteration_15_runtime_lifecycle_matrix.md)；当前验收判据见 [`acceptance.md`](acceptance.md)。
