# 玩法与表现模块边界（当前）

> **状态**：Phase 17/18 已完成并归档；本页只保留当前所有权、失败边界与不可回退规则。完整调查、批次差异和验证记录见 [`../archive/iteration_17_18_gameplay_module_matrix.md`](../archive/iteration_17_18_gameplay_module_matrix.md)。

## 1. 三类数据

| 类别 | 载体 | 所有者 | 规则 |
|:---|:---|:---|:---|
| 静态定义 | `EquipmentCatalog`、`DataKeys`、技能/材料表、关卡刷怪表、场景路径常量 | 模块常量与 `Resource` | 只读；运行时不得改写 |
| 实例状态 | `BaseLevel.current_stage`、实体字段、`LocalCoop` 槽位、`PlayerData.player_data` | 实体、`LocalCoop`、`PlayerData` | 按所有者写入，不跨域直写 |
| 表现资源 | 对象池节点、伤害文本、受击特效、音效/BGM、HUD 控件 | `Global` 与场景脚本 | 表现层不得提交领域状态 |

## 2. 归属与伤害

- 怪物受击统一进入 `BaseMonster.apply_role_hit`。
- 来源解析使用显式 `source_player`、载体字段/祖先链、`coop_damage_slot` 快照或 `LocalCoop.owner_hero`；无来源时伤害为 0，不回落 1P。
- 吸血、暴击、护甲、等级、Buff/无双按实际出手者槽位读取；不使用全局 `RoleProp`/`PlayerData` 代替槽位属性。
- 弹体、召唤物、法宝、武器弹体必须保留载体来源；新增创建入口必须传来源，不依赖场景加载顺序。

## 3. 对象池

四类池：伤害文本、受击特效、角色受击、音效。对象池归 `Global` 持有。

- 取出不保证重置；消费者必须通过 `setup()`/`recycle()`/`prepare_for_pool()` 清理。
- 归还前停止动画、清空文本/纹理/流与旧目标；不得携带上一轮归属或暴击状态。
- 池在档案结束时统一清理；关卡切换不整体清空，但不能把活动状态带过场景。

## 4. 关卡阶段与结算

- `BaseLevel.current_stage` 是阶段所有者；推进必须单调，不越级、不重复触发。
- 阶段推进、刷怪、出口和 HUD 读同一状态；子类不得绕过阶段表直接堆叠写入。
- 胜败/结算统一经 `LevelSettlement` 或等价结算入口；一次流程只提交一次保存。
- 返回、重战、自动重试不得重复发奖或重复保存；失败必须恢复奖励/装备/领取标记。

## 5. 成长命令

商店、锻造、强化、合成、分解、神铸、技能、任务领奖等成长操作遵循：

1. 校验容量、费用、前置条件；
2. 生成快照；
3. 扣除/产出；
4. 仅成功后提交保存；
5. 失败恢复档案、装备与面板选择状态。

不得先扣费后静默丢失产出，不得在失败路径保留部分提交。

## 6. HUD、输入与音频

- HUD 按注入的 `player`/槽位读取，不直接写 `PlayerData` 或档案。
- 输入读取与保存/档案写入不得出现在同一输入处理行；P1/P2 动作保持隔离。
- BGM/SFX 只经 `Global.add_bgm`/`add_sound` 或 `AudioRuntime` 公开入口；业务不直接创建 `AudioStreamPlayer`。
- 临时 UI 必须登记并有清理事件；表现层不得直接写档。

## 7. 模块 API 与依赖

- 父场景注入 `player`/`pet_panel` 等上下文；子模块通过公开方法查询，不反向控制父级业务。
- 新代码禁止 `/root/...` 和跨场景深层 `get_node()`；使用 `%UniqueName`、`@export` 或显式查询。
- 公开符号变更前查全部调用点；迁移一个职责时同步迁移全部生产消费者，不保留永久 facade。
- 静态守卫覆盖结算、命令快照、表现层写档、输入边界和路径预算；具体类别见 [`acceptance.md`](acceptance.md) §4。

## 8. 失败语义

| 场景 | 当前语义 |
|:---|:---|
| 无伤害来源 | 本次伤害为 0；不借用 1P |
| 池对象复用 | 消费者负责清理；未清理视为缺陷 |
| 阶段越级/重复 | 由 `BaseLevel`/关卡脚本守卫；新增入口必须使用统一推进 |
| 结算保存失败 | 回滚/保留重试；不得显示成功假象 |
| 成长保存失败 | 恢复快照与面板状态；不重复扣费/发奖 |
| 面板快照冲突 | `is_save_snapshot_in_progress()` 阻止打开/切换 |

历史调查、逐文件差异和旧计数见归档页；本页不作为批次日志。
